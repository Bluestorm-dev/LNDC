# Checklist V0.6.7

- [ ] L'onglet Admin > Test n'est visible qu'au Super Admin.
- [ ] Deux journées TEST sont affichées dans le générateur.
- [ ] Un match permet de choisir domicile, extérieur, stade, pays, date et heure.
- [ ] Le stade et le pays suivent automatiquement l'équipe domicile et restent modifiables.
- [ ] On peut ajouter et supprimer des matchs dans chaque journée.
- [ ] Les journées créées apparaissent aux joueurs avec le badge TEST.
- [ ] Un rappel 3 h / 30 min est généré par le Cron selon les préférences.
- [ ] Désactiver les matchs TEST les retire des pronostics et arrête les rappels.
- [ ] Réactiver les matchs TEST les remet en scheduled.
- [ ] Les matchs TEST ne modifient ni classement général ni classement Teams.
- [ ] Les matchs TEST ne ferment pas le choix Champion n°1.
- [ ] Supprimer les matchs TEST ne touche pas aux matchs réels.
- [ ] Vider tous les matchs exige le mot VIDER.
- [ ] Vider tous les matchs supprime aussi les anciens 4 matchs TEST initiaux.
