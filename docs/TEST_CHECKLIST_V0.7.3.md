- [ ] La création réussit sans erreur « Type de logo invalide ».
- [ ] `profiles.role` reste `player` après la création.
- [ ] `teams.captain_user_id` correspond au créateur.
- [ ] Une adhésion active `join_type='creator'` existe.
- [ ] Le créateur dispose des commandes de capitaine.
- [ ] Il conserve les fonctions joueur : pronostics, profil, classement, notifications.
- [ ] Un Admin/Super Admin conserve son rôle global s'il crée une Team.
- [ ] Aucun logo/pictogramme Team n'est réintroduit visuellement.
