Mode d’emploi

1. Déploie ce fichier dans le dossier tests/ du même site que Le Nid. 2. Connecte-toi au Nid avec un compte Super Admin. 3. Ouvre cette page dans le même navigateur. 4. Lance les tests automatiques. 5. Passe ensuite les tests manuels par version ou catégorie.

Le test Football-Data est volontairement non destructif : le Centre de tests vérifie la présence de la Function par requête OPTIONS, mais ne lance pas une synchronisation qui pourrait écrire des matchs.

Un 404 Football-Data pour la saison 2026/27 est un état attendu tant que le fournisseur ne publie pas cette saison. Il ne doit plus apparaître comme « Function absente ».
