LE NID DES CHAMPIONS — PATCH V0.9.10 R5 -> V0.9.11
=======================================================

Ce patch contient uniquement les fichiers nouveaux ou modifiés de la V0.9.11.

Installation :
1. Sauvegarder le projet et Supabase.
2. Extraire le patch à la racine de LNDC en remplaçant les fichiers.
3. Exécuter sql/HOTFIX_V0.9.11_EXISTING_DB.sql dans Supabase.
4. Déployer : supabase functions deploy sync-betclic-odds
5. Lancer : node tests\run-all-v0.9.11.mjs
6. Déployer GitHub Pages et faire Ctrl+F5.

Voir INSTALLATION_V0.9.11.txt pour le détail.
