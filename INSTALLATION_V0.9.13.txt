LE NID DES CHAMPIONS — INSTALLATION V0.9.13
===============================================

BASE : V0.9.12 R4.1

1. Sauvegarder Supabase et le dossier LNDC.
2. Remplacer les fichiers du patch ou utiliser le ZIP complet.
3. Exécuter dans Supabase SQL Editor :
   sql/HOTFIX_V0.9.13_EXISTING_DB.sql
4. Déployer la nouvelle fonction :
   supabase functions deploy admin-delete-user-v0913
5. Lancer :
   node tests\run-all-v0.9.13.mjs
6. Push GitHub Pages, fermer/réouvrir la PWA.

Aucun secret supplémentaire.
