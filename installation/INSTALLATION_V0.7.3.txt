LE NID DES CHAMPIONS — INSTALLATION V0.7.3

OBJET
Correction de la création de Team pour les comptes ayant le rôle global « player ».
Le capitanat est un rôle de Team et ne remplace jamais le rôle applicatif.

MISE À JOUR D'UNE BASE EXISTANTE
1. Ouvrir Supabase > SQL Editor.
2. Exécuter : sql/HOTFIX_V0.7.3_EXISTING_DB.sql
3. Déployer le contenu frontend de la V0.7.3 sur GitHub Pages.
4. Sur ordinateur : Ctrl+F5.
5. Sur mobile/PWA : fermer complètement puis rouvrir l'application.
